# Better-Gardens-Prototype
Group UX project (team of 5): "Better Gardens," a multigenerational community garden app with reminders, plant info, and a community hub. Figma prototype, usability-tested with 5 participants.

**[Figma prototype](https://www.figma.com/design/HGwgreywisgcOghxeX9ObN/INFO10003?node-id=242-89&t=oDOH5kQZDj0cLtbi-1)** ~ **[Full report (PDF)](Better-Gardens-Prototype
/Better Gardens Prototype Report.pdf)**

## Overview

Better Gardens is a community garden app designed for a multigenerational audience. It is simple enough not to overwhelm experienced gardeners and approachable enough for beginners, challenging the assumption that only older people enjoy gardening.

Our research found no existing app that combined all the features community gardeners need, and most existing apps weren't location specific. Better Gardens brings reminders, plant information, and community features into one app.

## Features

- **Home:** shortcut widgets for tasks, calendar, featured plants, and community, plus a notifications button
- **Plants:** scrollable feed with difficulty and season info, expandable "More Info," and "Add to Garden"
- **Tasks & Reminders:** to-do list and color-coded calendar views (maintenance, planting/harvest, important), switchable between community gardens
- **Community:** garden map, notice board, discussion area, and a "find nearby gardens" search with a distance slider
- **Profile:** activity stats and interests

## Process

1. **Research:** literature review and peer interviews. Younger and older participants differed on how much they wanted technology involved, but both agreed reminders would be a useful tool, so reminders became the lead feature.
2. **Low-fidelity prototype:** paper prototype of the core screens.
3. **High-fidelity prototype:** interactive Figma prototype with an earthy color palette and nine pages.
4. **Usability testing:** 5 participants (ages 19 to 57, from no gardening experience to avid home gardeners) completed four tasks: log in, add a community garden, find information on basil, and switch the task page from list to calendar mode. They thought aloud while sessions were recorded and timed, then completed the System Usability Scale questionnaire and gave general feedback.
5. **Iteration:** the team reviewed all feedback together and redesigned the prototype.

## Findings

**What worked:** users found the app straightforward, simple, and not overwhelming, and felt confident switching between pages.

**What didn't:** features felt unfinished, several buttons led to the same pages, the "Add gardens" feature was unclear, filters and specific searches were missing, and spacing and layout were inconsistent.

## Design Changes

| Finding from testing | Change we made |
|---|---|
| The plus icon for adding a garden was unclear | Replaced with an "Add Community Garden" button |
| No way to return to list view from the calendar | Added both calendar and checklist toggle icons |
| Users couldn't tell how nearby gardens were found | Added a distance slider and location search |
| Community switcher looked unfinished | Made dropdown menus interactive on Community and Tasks pages |
| "More Info" button did nothing | Made it interactive and expandable |
| Several buttons led to the same page | Removed redundant flows |
| Inconsistent spacing, padding, and placement | Standardized layout across pages |

## Limitations and Next Steps

- **Small sample:** only 5 participants, 3 of them university students, so the group didn't fully represent the multigenerational audience we designed for, and quantitative results are only indicative.
- **Tool constraints:** the team was new to Figma, which limited features like live maps and notifications, and many planned ideas ended up more basic than intended.
- **Next steps:** a larger follow-up study with more tasks on the revised prototype, plus further work on profile customization and smarter reminders.
